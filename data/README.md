# Data

## ⚠️ `KINOSTERNON_data_SIMULATED.xlsx` is SIMULATED

The file bundled in this folder is **synthetic demonstration data**, generated by `scripts/simulate_data.R`. It reproduces the published prevalence (%) and mean abundance per helminth genus and season (Table 2 of the manuscript), so the pipeline (`run_all.R`) can be run end to end without exposing the original field records. It is **not** the dataset that produced the published results, and downstream statistics (Fisher's test, PERMANOVA, GLM, etc.) computed from it will be qualitatively similar to, but not numerically identical to, the manuscript's Tables/Figures.

The original raw data are available from the corresponding author upon reasonable request (see main `README.md`, "Data availability").

# Expected input data format

Place your Excel file here (default expected name: `KINOSTERNON_data.xlsx`, sheet `Hoja1`), or point `run_all.R` to another location via the `KISC_INPUT_XLSX` / `KISC_SHEET` environment variables.

One row per turtle, with at least the following columns (names are matched case-insensitively and cleaned with `janitor::clean_names()`):

| Column (raw)              | Type    | Description                                                        |
|---------------------------|---------|----------------------------------------------------------------------|
| `estacao` / `estación` / `season` | text | Sampling season (e.g. "Chuva"/"Seca", "Rainy"/"Dry")           |
| `serpinema`                | integer | Number of *Serpinema pelliculatus* recovered                      |
| `spiroxys`                 | integer | Number of *Spiroxys figueiredoi* recovered                        |
| `falcaustra`               | integer | Number of *Falcaustra sanjuanensis* recovered                     |
| `nematophila`              | integer | Number of *Nematophila grandis* recovered                         |
| `area` (optional)          | text    | Collection site / municipality (not used in the models - see README) |

Empty cells in the genus count columns are treated as zero (uninfected for that species).

Note: exact GPS coordinates of collection sites are intentionally not distributed with this repository (see main README, "Data availability").
